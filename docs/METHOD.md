# 从词汇表到可调用的词汇网络

本书的设计目标，是帮助已有基础词汇量的学习者，把分散认识的单词组织成能够辨认、比较和主动提取的知识。关系分组负责导航，义项与搭配负责辨析，检索练习负责检验掌握。

## 词向量带来的设计启发

词嵌入把词映射为向量。以 word2vec 为代表的研究表明，从大量语料学习的向量可以表现出有用的语义和句法关系；余弦相似度则是检索相关候选的一种常用方式。[Mikolov 等，2013](https://arxiv.org/abs/1301.3781)

我从中获得的学习设计启发是：复习材料也可以按关系组织。看见一个词时，沿词形想到易混词，沿词义想到可比较的表达，再沿语境找到适合使用的搭配。这里借用的是“关系组织”的思路；本书将它落实为两条阅读路径和具体练习。

## 本书如何组织关系

**词形路径**关注字母顺序、词尾、词性和词族。比如 `adapt / adopt / adept`，先看清拼写，再把 `adapt to`、`adopt a policy`、`be adept at` 分别记入用法。

**语义路径**关注特定义项、搭配、程度、语体和使用场景。比如 `expand / enhance`，前者可以搭配教育机会的扩大，后者可以搭配教学质量的提升。正文为各组标明近义、相关或对照关系，学习任务是说清关系及其差别。

**主题路径**将全表组织为 81 个语义主题。需要准备环境、教育、经济等主题表达时，可以据此选词，再回到核心辨析核对用法。

## 把组织方式变成学习动作

检索练习是这套方法的关键。Karpicke 与 Roediger 的外语词汇实验发现，学习者首次正确作答后，继续进行检索练习能改善延迟回忆；实验将这种做法与继续学习等条件进行了比较。[Karpicke 与 Roediger，2008](https://doi.org/10.1126/science.1152408)

对应到本书，每组练习按以下顺序进行：

1. 看到英文，回忆词义；看到中文或语境，回忆英文。
2. 对照相近词，说出一个决定选择的差别。
3. 用目标词造句，再核对词性、搭配和表达对象。
4. 记录混淆点，在之后的复习中重新提取。

学习安排采用“先建立联系，再比较差异”。初次接触的词先逐个熟悉词形与词义，再进入成组辨析。Nakata 与 Suzuki 的实验中，133 名日本大学生学习 48 组英日词对，语义相关项目出现了更多干扰错误；间隔学习改善了一周后的保持。这为本书配套练习提供了一个具体设计依据：把辨析任务拆小，并安排隔时回忆。[Nakata 与 Suzuki，2019；2018 年在线发表](https://doi.org/10.1017/S0272263118000219)

次日、一周后、一个月后的回访可以作为个人复习安排的起点，实际间隔按错误率和备考时间调整。写作与翻译练习时，将中文意图作为提示，从候选词中选出符合语境的一项，让练习逐步接近考试中的输出任务。

## 成书中的工具分工

根据 PDF 附录“方法、来源与复核”记载，成书采用以下流程：

| 环节 | 方法 | 形成的内容 |
| --- | --- | --- |
| 词表恢复 | 从官方 PDF 的字符坐标恢复主词、派生形式和六级星号 | 保留原表对应关系的词表 |
| 形式展开 | 展开显式变体、恢复短语空格、合并重复拼写 | 8,013 个去重后的收录形式 |
| 释义整理 | 参考 ECDICT 与 CETVocabulary，补充并修订常用义 | 面向复习的短释与词性信息 |
| 词形候选 | 归一化插入／删除相似度，结合原表词族与编辑辨析 | 形近训练与 114 组核心辨析 |
| 语义候选 | BAAI/bge-small-en-v1.5 ONNX 权重，将“单词＋英文释义”编码为 384 维向量，CLS 池化及 L2 归一化 | 供语义整理参考的候选关系 |
| 内容编辑 | 按义项、差异、搭配和主题组织 | 227 组核心义项与用法、81 个主题 |
| 阅读与检索 | LaTeX 排版、双路径页码索引 | 400 页 PDF |

余弦相似度在这里负责发现值得检查的候选：同一语境中的词也可能具有相反含义，具体关系由义项和用法确定。最终版以辨析文本与主题地图呈现这些关系。
