# 六级词汇关系记忆宝典

**让 AI 成为新一代的学习搭子：把自己的学习需求，做成一本单词书。**

本项目记录了一次用 GPT-Astra 定制六级词汇书的实践：由作者提出提示词和内容要求，通过多轮生成、校验与修订，将公开词表组织成形近辨认与语义辨析两部分，最终以 LaTeX 排版为 PDF。

> 本 README 与仓库文章由 AI 生成，内容基于作者给出的提示词，并经过多次校验，删除了不合理之处。

**[下载完整 PDF](https://github.com/Lelyetia/Vocabulary-Book-for-the-College-English-Test-CET-6/raw/refs/heads/main/CET6_Final.pdf)** · [制作与学习原理](METHOD.md)

## 这本书包含什么

| 内容 | 规模与形式 |
| --- | --- |
| 完整成书 | 400 页 PDF，包含封面、正文、索引与来源说明 |
| 核心形近辨析 | 114 组，配合词族、拼写变体与相似拼写整理 |
| 核心义项与用法 | 227 组，按具体义项、搭配及关系标签组织 |
| 全词语义地图 | 81 个主题 |
| A–Z 索引 | 可分别定位词形页与词义页，电子版页码可点击 |

全书收录 **8,013 个去重后的词汇形式**，包含基础词、六级标星词、派生形式、短语与显式拼写变体。词表范围依据教育部教育考试院公开的《全国大学英语四、六级考试大纲（2016 年修订版）》。

## 我们怎样创建这本书

作者希望把词性、拼写和词义之间的关系放进同一本书，由此提出了“形近词与语义关联词分别整理、覆盖大纲词汇、生成完整书籍”的提示词要求。

制作过程从官方词表出发，展开派生形式与拼写变体，结合词典补充释义；借助拼写相似度和词向量检索提供候选，再由 AI 按具体义项、差异和搭配组织内容。作者通过多轮提示和校验推动修订，删除不合理的内容与分组，最终形成两部分正文和可点击索引，并完成 LaTeX 排版与 PDF 编译。完整流程见[制作与学习原理](METHOD.md)。

这个项目想展示的是：**每个人都可以结合自己的学习情况，用 AI 生成属于自己的内容。** 个人的目标、已有基础、关注点和偏好的材料形式，都可以成为定制内容的起点。本书呈现了其中一种具体选择。
